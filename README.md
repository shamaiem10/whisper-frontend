# Whisper Frontend

Frontend for the **Whisper** project — a travel memory & AI insight web app.  
Backend and full project: [Whisper Repo](https://github.com/shamaiem10/Whisper).

![Demo](travelani.gif)

## Features
- View and like travel memories
- Personalized AI insights on moods and vibes
- Responsive React + TailwindCSS UI

## Installation
```bash
git clone https://github.com/shamaiem10/whisper-frontend.git
cd whisper-frontend
npm install
npm run dev
```
Open 
```bash
http://localhost:5173
```
